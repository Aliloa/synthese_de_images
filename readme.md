# Touches utiles

- W/A/S/D: se déplacer
- Souris : orienter la caméra
- L : wireframe
- P : affichage normal (polygones remplis)
- F : activer / désactiver les lumières
- N : mode jour / nuit
- Échap : quitter l'application
